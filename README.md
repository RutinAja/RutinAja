# RutinAja

RutinAja is a lightweight maintenance-management SaaS for small Indonesian maintenance teams — replacing spreadsheet-based PM/CM scheduling with:

- 🔔 Automated H-7 / H-3 / H-1 reminders via Telegram & WhatsApp
- 🗂️ Asset & schedule management
- 🚦 Status dashboard (green / yellow / red)
- 👷 Technician assignment
- 📊 One-click reports (Excel/PDF)
